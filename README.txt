ARBAAZ BEBAL - PORTFOLIO WEBSITE

FILES
- index.html      Home page
- about.html      About and experience page
- analytics.html  Sample analytics dashboard
- CV.html         CV page with Print / Save as PDF button
- contact.html    Contact details and email-preparation form
- style.css       Shared responsive styling
- script.js       Mobile navigation, reveal effects, footer year and contact form
- analytics.js    Chart.js dashboard setup

HOW TO OPEN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser.

JAVASCRIPT
JavaScript is included for the mobile navigation, subtle scroll reveal, automatic footer year,
contact email preparation and interactive charts. The charts load Chart.js from a CDN, so an
internet connection is required for those charts.

IMPORTANT CUSTOMIZATION
- Replace the generic LinkedIn and GitHub links with your own profile URLs.
- Confirm the employment dates and all CV details before publishing.
- Add your profile photo only if you want one; the current design does not require an image.
- Analytics charts contain illustrative sample figures only. Replace them with verified project
  data and explain the source before presenting them as actual analysis.
- The contact form opens the visitor's default email application. It does not send messages
  directly from the website. Direct website submissions require a trusted form service or backend.
- Update the phone number and email address if either changes.

CV PDF
Open CV.html and select "Print / Save as PDF". Choose "Save as PDF" in your browser's print dialog.
